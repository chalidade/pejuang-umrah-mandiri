# Panduan tim konten

Isi tab **Panduan → Destinasi** dan **Panduan → Tips** bisa diubah tanpa ngoding, langsung dari aplikasi.

## Sekali saja di awal

1. Buat akun GitHub (gratis) di https://github.com/signup.
2. Minta admin mengundangmu: repo `pejuang-umrah-mandiri` → Settings → Collaborators → Add people. Terima undangannya dari email.
3. Buat kunci akses di https://github.com/settings/personal-access-tokens/new
   - **Repository access:** Only select repositories → `pejuang-umrah-mandiri`
   - **Permissions → Repository permissions → Contents:** Read and write
   - Klik **Generate token**, lalu salin kuncinya (diawali `github_pat_`).
4. Buka https://pejuangumrah.my.id/kelola (atau Pengaturan → Kelola konten), tempel kuncinya, lalu **Masuk**.

## Setiap kali mengisi konten

1. Pilih **Destinasi** atau **Tips**, lalu **+ Tambah** atau **Ubah**.
2. Isi formulirnya:
   - **Penjelasan:** tekan Enter dua kali untuk paragraf baru.
   - **Tips / Poin-poin:** satu per baris.
   - **Link Google Maps:** boleh kosong. Kalau kosong, aplikasi mencari otomatis dari nama tempat.
3. Tekan **Simpan**. Ulangi untuk konten lain.
4. Tekan **Terbitkan**. Sekitar 2 menit kemudian perubahan muncul di aplikasi semua orang.

## Aturan isi

- Tulis sendiri. Jangan menyalin dari aplikasi, buku, atau situs lain tanpa izin.
- Hindari harga dan jam buka yang pasti: cepat berubah.
- Hal yang menyangkut ibadah dicek dulu bersama mutawwif.

## Kalau ada masalah

- **"Belum bisa diterbitkan"**: baca daftar yang muncul, lengkapi bagian yang disebut.
- **"Kunci tidak berlaku"**: buat kunci baru (langkah 3), lalu masuk lagi.
- **"Ada anggota tim lain yang baru menerbitkan"**: ketuk Muat ulang, lalu ulangi perubahanmu.
- Konten yang rusak tidak akan tayang: aplikasi tetap memakai versi terakhir yang benar.
